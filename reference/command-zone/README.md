# Command Zone reference notes

Summaries of The Command Zone podcast episodes used as source material for `DECKBUILDING-SOP.md`. They were built from the episodes' auto-generated captions, so some card names may be garbled. Verify any card text via Scryfall before relying on it.

The SOP is the method; these notes are the *why* behind it. Read the relevant note when a section of the SOP points to it, or when a deck runs into the problem an episode covers.
